# 教程正文 · 目录与阅读指南

> 这是《Agent Zero To One · 从零开始学 AI Agent》的 **17 章教程正文**（第 00–16 章）：从"第一次调用模型"到"独立交付一个多智能体应用"，每一章都有一个可运行的产出。

**怎么用这个目录：** 找章节 → 看前置 → 点开正文 → 跑对应代码。所有代码都在 `code/` 下，**没有 API Key 也能跑**（`AGENT_MOCK=1` 离线模式）。

---

## 阶段一 · 起步：先跟模型说上话（第 1 周）

这一阶段只解决一件事：**让你亲眼看到模型对一个请求作出了回答**，并且知道这一次请求在网络与计费上到底发生了什么。刻意做到零第三方依赖、零成本——不装包、不要 Key，就没有网络、镜像、版本冲突这三座山。

| 01 | [认识 AI Agent](第01章 认识AI-Agent.md) | 分清 Chatbot / Workflow / Agent / Multi-Agent，知道什么时候**不该**用 Agent | 第00章 | 2.5 小时 | `ch01_first_call.py` |

## 三种阅读方式

**1. 顺序学（默认，推荐给 0 基础）**
从第 00 章开始，按顺序往下。每章花 2~8 小时：**先读正文 → 离线跑通代码 → 接真模型改一个地方 → 写进 `03-学习笔记/`**。第 05、07、08、12 章是全书四个硬骨头，建议各分两次学，别硬撑。

**2. 按需查（有基础、带着任务来）**
用下面的"问题 → 章节"对照直接跳，不必从头读：

| 你的问题 | 去哪一章 |
|---|---|
| 模型输出格式不稳定、JSON 解析老失败 | 第 03 章 |
| 想让模型调用我自己的函数 / 接外部 API | 第 04 章 |
| Agent 死循环、停不下来、工具报错要重试 | 第 05 章 |
| 任务步骤多、需要先规划再执行 | 第 06 章 |
| 多轮对话变长后变笨、成本失控 | 第 07 章 |
| 要回答"我们自己的文档里怎么说" | 第 08 章 |
| 同一套流程反复写进 prompt | 第 09 章 |
| 工具要在多个应用间复用、要接外部服务 | 第 10 章 |
| 想拆多个 Agent 协作 / 评审 | 第 11 章 |
| 说不清"到底变好了没有"、要防注入 | 第 12 章 |
| 要上线、要控成本与延迟 | 第 13 章 |
| 想把公共逻辑抽出来自己造框架 | 第 14 章 |
| 要做一个能写进简历的完整项目 | 第 15 章 |
| 要独立做毕设 / 准备面试 | 第 16 章 |

**3. 复习用（面试前 2 周）**

- 只读每章的 **`## 本章小结`**（10 分钟扫完 17 章）；
- 只做每章的 **`## 自测题`**（折叠答案，先自己答再看）；
- 把 `## 本章产出 / 交付标准` 当清单逐条打勾，**答不上"验收问句"的章节就是薄弱环节**；
- 配合 `02-Wiki/面试题库/` 的专题与速查表查漏。

## 每章的统一结构

每章都按同一套结构写，你知道自己会看到什么：

| 部分 | 作用 |
|---|---|
| `> 本章目标 / 预计用时 / 前置章节 / 配套代码` | 开头的引用块：先看这个，确认前置章节都学过 |
| `## 0. 开篇：一个真实的问题` | 先讲**没有它会出什么问题**（真实翻车场景），再引出本章要解决什么 |
| 正文若干节 | 每节按"**为什么需要 → 它是什么 → 怎么用**"展开；关键取舍给对比表与具体数字 |
| `### ⚠️ 常见坑` | 每个主要小节末尾：现象 → 原因 → 怎么改，写的是真实踩过的坑 |
| `## 本章小结` | 5~10 条要点，复习时只看这里 |
| `## 动手练习` | 3~4 个改造任务，每个都写明"目标是什么" |
| `## 自测题` | 4~5 题，答案折叠在 `<details>` 里，先自己答 |
| `## 本章产出 / 交付标准` | 可勾选清单 + 一个 **验收问句**（答不上来说明没学透） |
| `## 结语与下一章` | 下一章要解决什么问题、为什么现在讲 |

## 学习建议

**别只读代码。** 正文里的代码是**讲解用**的片段，`code/` 里的才是能跑的完整实现——但两者都不是让你抄的。正确的用法是：读完正文，想象"如果让我写会怎么写"，再去看实现对比差异。**光看不写，三个月后你只会说"我学过"；每章改一处，三个月后你能说"我做过"。**

**别跳过动手练习。** 每章的"动手练习"都是刻意设计的——它让你改一个地方并**预测**结果，然后验证。这正是 `00-配置/进度看板.md` 里"三个勾"的后两个：能讲清、改得动。只跑通代码只算第一个勾。

**别跳过离线模式。** 没配好 Key 不是不开始的理由：`AGENT_MOCK=1` 会真实走完循环、解析 tool_call、执行工具、做检索排序，只是"想"的部分用规则替代。**先离线看流程，再在线看效果**，排错时你会省一半时间。

**卡住了怎么办（按顺序试）：**

1. **先看报错本身**：报错信息里的文件、行号、异常类型，80% 的问题看一眼就知道；
2. **确认是不是环境问题**：Python 版本（需要 3.9+）、是否在 `code/` 目录下运行、是否装了 `requirements.txt` 里的包；
3. **回退到最小案例**：把代码砍到只剩出问题的那几步，去掉所有无关输入；
4. **跑到离线模式复现一次**：如果离线正常、在线失败，问题在 Key / 网络 / 模型名，而不在你的逻辑；
5. **看当章的 `### ⚠️ 常见坑`**：你遇到的大概率是别人踩过的；
6. **问 AI 教练**：把 `学习中枢.md` 配给你的 AI 助手，直接说"我在第 07 章卡住了，`ch07_memory.py` 报 XXX，我已经试过 YY"——它知道你的档案与进度，会按你的水平给提示；
7. **记下来**：无论最后怎么解决的，写进 `03-学习笔记/`。**卡点记录比顺利记录更值钱**，面试里讲的失败故事都来自这里。

**最后一条：每章学完，用一句话说出"它解决了什么问题"。** 说不出，就说明还没学完——回去看开篇那一节。
