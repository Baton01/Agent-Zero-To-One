## 一、本周目标

- [ ] 能写出**六段式 Prompt**（角色 / 任务 / 约束 / 输入 / 输出格式 / 示例），并说出每一段"不写会出现什么现象"
- [ ] 能默写 `safe_parse_json` 的四步处理顺序：剥壳 → 括号截断 → 引号/逗号修复 → 字段与类型校验
- [ ] 手写实现"错误回灌"重试循环（把上次原文 + 具体错误信息一起发回去），并解释它为什么比"重复同一请求"有效
- [ ] 说清 JSON mode 的两个边界：只保证"合法 JSON"，不保证字段名与类型；并写出一段不支持时的降级代码
- [ ] 跑通 7 种畸形输入的处理路径，统计一次"同一 prompt 跑 20 次"的 JSON 合法率，把**实测数字**写进本笔记
- [ ] 完成批量抽取器：单封失败不中断整批，末尾输出失败清单、重试次数分布与估算成本

**过关标准：** 给一段畸形模型输出（形如 ```` ```json {"a": 1,} ``` ````），你能**先预测** `safe_parse_json` 会走到第几步、最终是成功还是返回 `None`，然后跑代码验证预测正确。
