## 一、本周目标

- [ ] L7 **可复用 Skill Pack**：≥2 个 `SKILL.md`，每个都有完整的"何时使用 / 不适用 / 步骤 / 验收标准"，`description` 里有用户真实说过的话，`scripts/` 与 `templates/` 资源**真实存在且能独立跑**
- [ ] L7 给出 A/B smoke test 报告：固定任务集 6–10 条、**等长基线**、每任务重复 3 次、代码判定、同时报成功率与 token 变化
- [ ] L7 说清渐进式加载的收益：报出"目录 token / 命中正文 token / 全量注入 token"三个数
- [ ] L8 **生产级 Harness**：evals、trace、权限、CI、回放、成本报告六件齐全，且**每件都能演示**
- [ ] L8 的评测跑进 CI：mock 每次提交跑（测框架逻辑），在线全量定期跑（测模型行为）；通过率 < 75% 或恶意 / 无答案用例失效时**返回非零退出码**
- [ ] L8 有回放能力：给定一个 `trace_id` 能重跑同一条用例并对比差异（改了 prompt / 工具 / 模型后是否退化）
- [ ] L8 有成本报告：按任务 / 按模型 / 按天三个维度给出 `$/完成任务`、平均步数、P95 延迟，并能指出最贵的三类请求
- [ ] 两个项目都进 `04-Outputs/`，各写一份作品记录（一句话 / 解决什么问题 / 技术方案 / 关键指标 / 踩过的坑 / 如果重做会怎么改 / 演示方式）

**过关标准：** 把 L8 的仓库交给一个没参与过的同学，他照 README 能在 10 分钟内跑出你的指标数字；跑不出来，问题不在他。
