## 一、本周目标

- [ ] 实现"带引用回答"：证据表存**原文片段 + 字符偏移**，生成后逐条机械校验（编号存在 + 引用片段能在原文对上）
- [ ] 说清为什么"只要求模型标注引用"不够，必须做机械校验；并实现"校验失败 → 重试一次 → 拒答"的完整降级链路
- [ ] 说清拒答阈值为什么要用评测集**扫**出来（如 0.25 / 0.35 / 0.45 各跑一遍比数），而不是拍一个数
- [ ] 说出 RAG 五个评估指标并区分职责：`Recall@K` 决定上限、`Faithfulness` 决定可信度，两者必须分开测
- [ ] 建一份 20 条起的评测集（JSON），含至少 3 条 `must_refuse=True` 的无答案问题，且问题用**口语化写法**而不是抄文档原文
- [ ] 把 bad case 归到四类：切片问题 / 检索未召回 / 召回了没用 / 模型瞎编，每类至少 1 例并写明怎么修
- [ ] 说清 RAG / 微调 / 长上下文三者的边界：RAG 解决"私有 + 易变 + 要出处"，微调解决"风格与行为"，长上下文只适合小文档

**过关标准：** 能指着你自己的评测报告回答："如果 `Recall@5=0.95` 但 `Faithfulness=0.4`，最可能的问题在哪、我先改哪一环"。答不上来说明评估还没真的跑起来。
