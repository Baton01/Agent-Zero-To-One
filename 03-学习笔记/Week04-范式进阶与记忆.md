## 一、本周目标

- [ ] 说清 CoT 的适用边界：只对"需要推理且模型知道相关知识"的任务有效；对事实检索类只会给幻觉加戏；严格 JSON 输出别混 CoT
- [ ] 说清 Plan-and-Execute 用"先规划"换全局视野与**线性成本**，代价是计划错了会一路错，因此 **replan 不能省**；并给出判断分界线（第 2 步的输入是不是第 1 步的输出）
- [ ] 解释 Reflection 的 L1（自我批判，不稳定，最多一轮）与 L2（外部信号：测试、编译、检索证据，可靠）差一个数量级的原因
- [ ] 说出反思循环的四个保命设计：具体 rubric、定位到原文片段、问题没变少就停、返回"最好的一版"而非"最新的一版"
- [ ] 画出三层记忆的信息流图，标出每层的**读写时机**与**失效策略**：短期（每轮重发的 `messages`）/ 会话（摘要 + 结构化事实）/ 长期（跨会话 key-value 档案）
- [ ] 说清上下文工程的四个动作：选择（排序 + 预算内贪心）、压缩（按清单保留/丢弃）、隔离（子任务只回传结论）、编排（动态组装 + trace 留痕）
- [ ] 跑通 `ch07_memory.py`，30 轮后所有断言为 True，并交出一张 token 对比表（不管理 / 滑动窗口 / 摘要压缩）

**过关标准：** 拿你手上的 3 个真实任务，逐个说出"该用哪个范式、为什么"，并说明兜底开关在哪；同时能回答"没有外部信号的反思为什么最多一轮"。
