## 一、本周目标

- [ ] 从零手写一个**不依赖任何框架**的工具调用循环：参数校验 → 类型转换 → 执行 → 结果回填，并能画清"模型填表 → 代码代跑 → 结果回报"三步
- [ ] 写出一个"模型看了就会用"的工具 `description`：说清做什么 / 何时用 / **何时不用** / 返回什么
- [ ] 把工具异常翻译成**模型能行动的一句话**（形如 `{"ok": false, "error": "参数缺失：city，请提供城市中文名，例如 北京"}`）喂回去，而不是抛给用户
- [ ] 说清 `tool_call_id` 的作用；一次请求里模型申请了 2 个工具、你只回 1 条 `tool` 消息会发生什么
- [ ] 实现并**各自触发一次**五种停止条件：最大步数、重复动作、无进展、成本上限、超时，并打印出对应的 `stop_reason`
- [ ] 说清为什么现在的 ReAct 应该用**原生 Function Calling 承载 Action、`content` 承载 Thought**，而不是正则解析文本格式
- [ ] 给危险工具加人工确认（`requires_confirmation`），并说明为什么"路径校验不能只写在描述里"

**过关标准：** 白板画出 Thought → Action → Observation 循环，讲清"为什么显式思考能让模型自我纠正"，并说出五种停止条件各自拦住什么故障。三问都能答才算过关。
