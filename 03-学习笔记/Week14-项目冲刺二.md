## 一、本周目标

- [ ] L4 **代码审查 Agent**：读 diff → 按风险排序 → 给测试建议；采用**双阶段（生成 + 证伪）+ 置信度阈值 + 条数上限 + 风格类硬过滤**控制误报；大 diff 走三层降级并**显式声明覆盖范围**
- [ ] L4 的评估落地：20 个真实 diff，给出检出率与**误报率**两条曲线（阈值 0.6 → 0.7 时两者怎么变）
- [ ] L5 **浏览器 Agent**：页面观察 → 点击 / 输入 → 提取 → **失败恢复**（元素找不到怎么办、页面超时怎么办、被反爬怎么办）
- [ ] L5 接一个外部能力时优先走 MCP：说清你选的 Server 为什么用 stdio 或 HTTP，权限收到什么范围，并过一遍接入前检查清单
- [ ] L6 **Nano Coding Agent**：shell 执行 + 文件编辑 + **权限门** + session 持久化 + 上下文压缩（compact）；危险操作必须人工确认并展示完整参数
- [ ] L6 复用 mini harness 的分层：只改一个模块就能把 `Session` 从 JSONL 换成 SQLite，其余代码不动
- [ ] 三个项目都给出**成本账**：`$/完成任务`、平均步数、P95 延迟；L5 / L6 还要给出"单任务预算熔断"的实测拦截记录

**过关标准：** L4 能在 20 个真实 diff 上给出误报率数字；L5 能演示一次"元素找不到 → 换选择器 → 成功"的恢复；L6 能演示一次"危险命令被权限门拦下且用户拒绝后 Agent 继续"。
