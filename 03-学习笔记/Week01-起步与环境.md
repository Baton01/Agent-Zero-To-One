## 一、本周目标

- [ ] 不装任何第三方包（不用 `openai`、不用 `requests`），用标准库 `urllib` 手写一次模型调用，能指出 `choices[0].message.content`、`finish_reason`、`usage` 三个字段各是什么
- [ ] 用自己的话讲清四种形态的区别在于"谁决定下一步"：Chatbot（人）/ Workflow（代码）/ Agent（模型）/ Multi-Agent（多角色），并对一个**真实需求**给出"该不该用 Agent"的判断与理由
- [ ] 默写 Agent 的五个部件（模型、工具、循环、状态、停止条件），以及"缺了停止条件"会出现的具体现象
- [ ] 会数 Token、会算成本：中文 1 字 ≈ 0.6–1 Token、上下文窗口 = 输入 + 输出、Agent 5 轮成本 ≈ 单轮 7.2 倍
- [ ] 建好 `code/.env` 并用 `.gitignore` 排除，说得出自己正在用的 Python 绝对路径（`sys.executable`）
- [ ] 三个脚本离线跑通，并各在线跑一次

**过关标准：** 能不看笔记画出"脚本 → URL + Header + Body → 网关 → 模型 → 响应 JSON"的完整链路，并说清 `AGENT_MOCK=1` 能验证什么、不能验证什么（验证流程，不验证效果）。两件都做到才算过关。

## 二、预习：先想三个问题

> 读正文之前先自己想一想，读完回来对照。

1. 不装 `openai`、不装 `requests`，只用 Python 标准库，你能发出一次 HTTPS POST 吗？请求里最少必须有哪些 Header？缺 `Authorization` 会返回哪个状态码？
2. 三个"AI 客服"：① 模型只回文本、发货由人工点；② 代码写死"查订单 → 查政策 → 写回复"；③ 模型自己决定先查订单还是先查政策。它们分别属于哪种形态？**谁决定下一步**？
3. 同一段 800 字中文，为什么不能按"字数"给客户报价？如果一个 Agent 循环要跑 5 轮，为什么成本不是单轮的 5 倍？
