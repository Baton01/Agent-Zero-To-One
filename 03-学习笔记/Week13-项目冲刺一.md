> **本周章节：** 项目阶梯 L1 计算器 Agent（第 04 / 05 章）→ L2 网页研究 Agent（第 06 / 08 章）→ L3 文档问答 Agent（第 08 章）

## 一、本周目标

- [ ] L1 **计算器 Agent**：手写最小 tool call loop（+ − × ÷ 四则运算 + 错误处理），至少 3 个工具，离线与在线都跑通；写出"参数错误 → 喂回模型 → 它改对"的完整日志
- [ ] L2 **网页研究 Agent**：给出研究主题后先搜后写，产出**带可追溯引用**的报告；证据表存原文片段 + 字符偏移，禁止模型自己写 URL；单一事实至少 2 个独立来源
- [ ] L3 **文档问答 Agent**：完整 RAG 链路（切片 → 检索 → 融合 → 重排 → 带引用回答 → 拒答），并给出切片对比实验（`Hit@5` 前后数字，参考 0.74 → 0.88 的量级）
- [ ] 每个项目都能回答阶梯的四个问题：**为什么这样选 / 效果如何度量 / 失败如何恢复 / 成本如何控制**
- [ ] 每个项目都有 README 四问（怎么跑 / 怎么配 / 怎么扩展 / 已知限制 ≥3 条）、离线模式、可复现命令
- [ ] 每个项目至少 1 个**反指标**：L2 用"编造率"（引用对不上的句子占比），L3 用"误拒率"（该答却拒答的比例）
- [ ] 三个项目各写一句简历写法（一句话 + 三个亮点 + 一个量化结果），数字先用实测值占位

**过关标准：** 每个项目都能在 3 分钟内演示完，且演示中**主动展示一个失败场景的降级处理**——只演 happy path 的不算过关。
