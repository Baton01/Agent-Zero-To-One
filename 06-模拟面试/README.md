# 模拟面试

> **怎么用这套模拟面试：** 这是一套"当场练"的设施，不是又一份题库。你可以在任意 AI 助手里跑一场 45 分钟的面试，也可以在网页上逐题自答看参考思路。
> **五个文件的分工：** [[06-模拟面试/01-面试全流程脚本]]（怎么问、怎么控时间）· [[06-模拟面试/02-面试官提示词]]（让 AI 扮演面试官）· [[06-模拟面试/03-题库与追问链]]（五轮 65 题）· [[06-模拟面试/04-评分表与反馈模板]]（怎么打分、怎么复盘）· [[06-模拟面试/05-面试记录]]（每一次都归档）

## 一、先看一个真实场景

上周有个学员做完第一次模拟面试，回来跟我说：「这些题我都背过，还是被问懵了。」

我不太信，让他把过程复述一遍。

> **我：** 你介绍一下最有分量的那个项目。
>
> **他：** 我做了一个企业文档问答系统，基于 RAG，用了混合检索和 Rerank，做了引用校验，Recall@5 是 0.88。
>
> **我：** 等一下，0.88 这个数是怎么算出来的？
>
> **他：** 就是……检索对了的比例。
>
> **我：** 谁标的 gold？30 条样本里多跳和无答案各几条？
>
> **他：** 这个我没细分，是我自己看了一遍，觉得检索到了就算对。
>
> **我：** 那你上次改切片参数，指标是涨了还是跌了？
>
> **他：** 涨了。
>
> **我：** 涨了多少？
>
> **他：** 具体数字我记不太清了，反正效果挺好的。

到这里，面试官心里的判断已经出来了：**这个人可能真的做过，但他不知道自己做的事情的价值在哪。**

他的问题不是不会做，而是**没练过怎么讲**。

这类情况非常普遍。学过的东西在脑子里是"一堆做过的事"，面试要的是"一条能站得住的论述"：**结论 → 依据 → 边界**，每一句后面都挂着数字或一次踩坑。

所以这个模块只解决一件事：**把"我做过"练成"我讲得住"。**

## 二、会做不等于会讲，面试是独立技能

不少人以为面试是学习的副产品——学得好自然答得好。不是。它们是两项不同的技能，练法也不同：

| | 学习 | 面试 |
|---|---|---|
| 目标 | 把事情做对 | 在两小时内让陌生人相信你做过、想过、知道边界 |
| 反馈 | 代码跑通、指标提升 | 对方的追问能不能接住 |
| 失败的样子 | 跑不起来 | 答得对但说不清口径，被追问两层就露 |
| 练法 | 读、写、跑 | **出声讲、被人追问、复盘记录** |

**关键差别在"追问"。** 面试官不会满足于第一个答案——他会下钻问机制、横扩问边界、上抬问取舍。你答得越顺，他追得越深。

而"背答案"的人恰恰死在这一步：他背的是**结论**，追问要的是**结论背后的取舍与口径**。这就是为什么 [[06-模拟面试/03-题库与追问链]] 里每一道题都带「追问」字段——**那道题不是终点，是入口。**

还有一件必须说清的事：**模拟面试不是考试，是排练。** 你在这里答错一次，成本是零；在真面试里答错一次，成本是一个 offer。所以练的时候要往难里练：**故意让 AI 追问三层**，故意挑你不熟的那一轮。

## 三、怎么用：两种方式

### 方式一：AI 教练带练（推荐）

1. 打开 [[06-模拟面试/02-面试官提示词]]，把里面那段提示词**整段复制**
2. 粘贴给任意 AI 助手（Claude Code / Cursor / 网页版对话模型都行），作为系统提示词或开场消息
3. 补一句你的情况：「我是做 RAG 方向的，投 AI 应用开发岗，做过 L3 文档问答和 L4 代码审查，跑标准技术面」
4. 然后说「**开始面试**」

接下来 AI 会按 [[06-模拟面试/01-面试全流程脚本]] 走流程：自我介绍、逐轮提问、一题一问等着你答、按你的回答决定追不追问。**每轮结束它会给你一段小结，全场结束给你一份报告**（总分、各维度得分、三个最该补的短板、对应的复习文件）。

**这一步的关键是出声。** 打字答题和开口答题完全是两件事——打字可以删改，开口是一次性的。把语音输入打开，或者干脆对着 AI 说。你会立刻发现哪些话是自己说不顺的。

### 方式二：网页端自测

打开项目网页（双击 `web/index.html`）→ 侧栏「模拟面试」，逐题自答：

- 先只显示**题面**，出声答一遍（30 秒版本）
- 再展开看**参考思路 / 加分 / 扣分 / 追问**
- 拿不准的题点「关联」跳到对应章节重读

网页端适合零碎时间过一遍、检验记忆；但它没法追问你，**真正的练习还是要在 AI 那边做**。

## 四、三种场次：按你有多少时间选

| 场次 | 时长 | 跑哪几轮 | 什么时候用 |
|---|---|---|---|
| **快问快答** | 20 分钟 | 只跑 Agent 知识轮，挑 8–10 题 | 通勤、睡前，检验记忆与口径 |
| **标准技术面** | 45 分钟 | 算法轮 12 分钟（1 题）＋ Agent 知识轮 20 分钟（6–8 题）＋ 项目深挖轮 13 分钟（3–4 题） | 已经有项目，准备投递 |
| **完整终面** | 90 分钟 | 五轮全跑：算法 15＋知识 25＋项目 20＋系统设计 20＋行为压力 10 | 毕设完成后、拿到面试通知后 |

三场共用的规则只有一条：**时间盒到点就换轮，哪怕上一题没答完。** 真面试就是这样，面试官不会因为你答得好就多给你二十分钟。

## 五、什么时候该来练

不要在学完 17 章之后才第一次打开这里。按进度分成三个入口：

| 你现在的进度 | 练哪一轮 | 为什么是这个时间点 |
|---|---|---|
| 学完 [[docs/第05章 ReAct最小Agent-Loop]] | **Agent 知识轮**（K1–K20） | 这时你已经跑过 Agent 循环，第 01–05 章的概念能不能讲清，这一轮立刻就能验出来 |
| 做完 L1 / L2 项目 | **Agent 知识轮 + 算法轮** | 项目还太薄，撑不起深挖；先用知识轮和算法轮把基本功过一遍 |
| 做完 L3 文档问答或 L4 代码审查 | **项目深挖轮**（P1–P15） | 有数字可报了，这时候练的是"数字怎么讲、口径怎么圆" |
| 做完 L6 / L8 | **完整终面** | 系统设计与故障排查能撑住 20 分钟，可以开始跑全程 |
| 毕设完成、要投简历了 | **每隔两天跑一次完整终面** | 见 [[06-模拟面试/05-面试记录]] 的复练节奏 |

对照 [[01-Raw/03-项目阶梯与能力对照表]] 的项目阶梯看更清楚：**每做完一档，就回来练对应的那几道题**——L1/L2 练 K 轮，L3/L4 练 P 轮，L6/L8 练 D 轮。

## 六、怎么打分、怎么复盘

打完一场必须留下三样东西，否则这场基本白打：

1. **分数**：按 [[06-模拟面试/04-评分表与反馈模板]] 的七个维度打分（每题按 0/1/2 记，最后换算成维度分）
2. **卡住的题号**：写下来，比如「K8、P2、D6」——这三个题号就是你下周的复习清单
3. **三个短板 + 下一步行动**：每条行动要能当天开始做（"重读 [[docs/第08章 RAG全链路]] 的评估一节并补 2 条多跳样本"，而不是"加强 RAG"）

记录格式与归档规则见 [[06-模拟面试/05-面试记录]]。**同一套题隔两周再打一次，分数变化比单次分数有意义得多。**

## 七、三个最容易白练的坑

**坑一：只读不答。** 把参考思路读一遍觉得"我会了"——那是识别，不是回忆。**必须出声答一遍再看答案**，哪怕答得很难看。

**坑二：只在脑子里过。** 默读时你以为自己讲得清楚，一开口才发现全是"那个啥""大概""差不多"。**出声是唯一的检验方式。**

**坑三：只练会的题。** 挑自己熟的轮次反复练，分数很好看，短板一点没动。**每次至少挑一道你最怕的题**——K 轮的数字题、P 轮的口径题、D 轮的降级题，都是重灾区。

## 八、练到什么程度算过关

过关不是"题都能答上来"——题库就那些题，背三轮谁都能过。**过关的判据只有一个：你的答案里有没有"机制 + 数字 + 边界"这三样东西。**

拿项目深挖轮里最常见的一问做对照：

> **面试官：** 你的文档问答系统召回效果怎么样？

| | 回答 | 面试官听到的信号 |
|---|---|---|
| ❌ 练之前 | 「效果挺好的，召回率挺高的，我们用了混合检索和 Rerank」 | 只有结论和名词，追问一层就见底 |
| ✅ 练之后 | 「30 条自建评测集上 Recall@5 是 0.88，改之前 0.74。改动主要是两条：结构切分替掉固定长度切分（400 字、overlap 60），以及向量加 BM25 做 RRF 融合。**代价是延迟从 1 倍涨到 1.5 倍**，Rerank 候选集我从 50 砍到 20 才把 P95 压回 4.2 秒。」 | 有口径、有对比、有机制，**并且主动说了代价** |

**四个自检项（对每一道你练过的题问一遍）：**

- [ ] 我这句话里有没有**数字或口径**？（没有就补一个）
- [ ] 我有没有主动说一句「**代价是……**」或「**什么情况下不成立**」？（没被问就说了才算过关）
- [ ] 如果面试官接着问「**这个数怎么测的**」，我能不能给出三段式（口径 → 样本 → 局限）？
- [ ] 我有没有准备一个**失败故事**（现象 → 定位 → 根因 → 修法 → 修完的数字）？

**四项全打勾，这一题才算练过。** 四项里最容易被跳过的是第三项——很多人有数字，但说不出口径，而面试官几乎一定会追这一层。

## 九、和别的模块怎么配合

```
学（docs/ 17 章 + code/）
   ↓
查漏（02-Wiki/专题总结 + 速查表）
   ↓
讲得出（02-Wiki/面试题库：答案对不对）
   ↓
讲得住（06-模拟面试：被追问三层还站不站得住）★ 你在这里
   ↓
投出去（简历与项目表达，见 01-Raw/03-项目阶梯与能力对照表 第四节）
```

**一句话收尾：** 题库让你"答得对"，项目文档让你"答得细"，这个模块让你"**答完还站得住**"——面试官听完你项目的那一刻，心里其实只有一个问题：**这个人是不是真的做过、想过、并且知道自己在做什么。**
