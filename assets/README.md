# assets · 配图与素材

这个目录放**图片和其他非文本素材**。目前是空的 —— 因为教程正文全部用文字和代码表达，不依赖截图。

## 什么该放这里

- 你在学习过程中画的架构图、流程图、时序图（导出的 PNG / SVG）
- 从别人文章里引用的图（**必须注明来源和许可**，否则不要放）
- 你自己项目的截图（用于 [[04-Outputs/README]] 里的作品记录）
- 演示用的示例文件（比如第 08 章 RAG 要用的测试文档，如果你想用真实的而不是脚本内置的示例）

## 什么不该放这里

- 教程正文里能写清楚的东西（本项目刻意不用截图 —— 文字可以搜索、可以复制、可以 diff）
- 大体积视频（放云盘，这里只放链接）
- 版权不明的素材

## 命名建议

用 `用途-描述.png` 的形式，例如：

```
assets/
├── 架构图-最小Agent循环.png
├── 架构图-mini-harness模块依赖.png
└── 截图-第08章检索排名对比.png
```

正文里引用时用相对路径：`![最小 Agent 循环](assets/架构图-最小Agent循环.png)`。

> **提示：** 如果你只是为了自己看懂而画图，画完直接放进 `03-学习笔记/` 对应周的笔记里就行，不必放这里。`assets/` 留给"值得在正文里长期引用"的图。
